Plate labeller
Plate mode (P): tight box around the number plate only. Vehicle mode (V): box around the whole vehicle (CNG, rickshaw…). No legunas on this route.
Dashed ? boxes are unreviewed model suggestions. Delete wrong ones, fix the rest, then A accept all remaining. Unreviewed suggestions are saved as ignore, never as plates.
Draw: drag on empty space · Move/resize: drag box / corner
Zoom: scroll · Pan: Space+drag or right-drag · F fit
Tab/Shift+Tab next/prev box (zooms in) · Del delete · Enter accept selected
1–5 type · I ignore (unsure, far, rickshaw tag) · O model vehicle overlay
Ctrl/⌘+Enter save & next · S save · Esc deselect
